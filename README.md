# Aether — публичный сайт

Лендинг Windows-приложения Aether: возможности, демонстрация интерфейса и информация о тестовом выпуске.

Это самостоятельный статический сайт. Исходники приложения, установщики и данные профиля в этот репозиторий не входят. Скриншоты показывают встроенные демонстрационные примеры.

## GitHub Pages

Файлы готовы для размещения из корня ветки main. Для включения сайта: Settings → Pages → Deploy from a branch → main → /(root) → Save.

После включения Pages ожидаемый адрес: https://alexmercer1337.github.io/aether-site/

Отдельный этап сборки, npm-зависимости и сервер Node.js не требуются. Файл .nojekyll отключает обработку Jekyll. Стили, скрипт и изображения используют относительные пути.

## Обновление

Обновляйте файлы основного сайта, сохраняя структуру assets/. Изменения выбранной ветки после включения Pages публикуются автоматически. Страницы сравнения дизайна и локальные отчёты проверки сюда не загружаются.

## Материалы

Шрифт Golos Text распространяется по SIL Open Font License 1.1; текст лицензии — [assets/fonts/golostext-OFL.txt](assets/fonts/golostext-OFL.txt).

Установщик хранится в отдельном [репозитории выпусков](https://github.com/AlexMercer1337/aether-releases/releases). Данные о версии и контрольная сумма на странице обновляются вручную после проверки конкретного публичного файла.
