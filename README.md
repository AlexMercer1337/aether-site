# Aether

Задачи, учебные планы, книги и личные записи — в одном приложении для Windows.

- Планируйте день и следите за ближайшими событиями.
- Продолжайте учёбу с нужного места и отмечайте прочитанные книги.
- Записывайте идеи, ведите дневник и сохраняйте списки игр и фильмов.

Доступна [тестовая версия для Windows x64](https://github.com/AlexMercer1337/aether-releases/releases/tag/v0.1.0-beta.17). Стабильного выпуска пока нет.

Для поиска в каталогах книг, фильмов и игр нужен персональный код беты. Скачивание приложения не предоставляет код доступа.
